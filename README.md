# Healthcare-Analytics-Dashboard
The dataset contains 500 patient records with attributes such as age, gender, BMI, blood pressure, cholesterol level, diabetes status, smoking habits, hospital visits, and treatment costs.

The dashboard includes:
- Age distribution histogram
- Gender distribution bar chart
- BMI vs Treatment Cost scatter plot
- Average hospital visits by age group line chart
- Pie charts for smoker and diabetic proportions
- KPI cards for average treatment cost, average BMI, and total hospital visits
- Interactive slicers for filtering by gender, diabetes, and smoking status
